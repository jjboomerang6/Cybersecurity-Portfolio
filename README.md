## Tools Used

| Tool | Website | Description |
|---|---|---|
| Autopsy | [Website](https://www.autopsy.com/) | A digital forensics tool used to analyze disk images, recover deleted files, and investigate digital evidence. |
| FTK Imager | [Website](https://www.exterro.com/digital-forensics-software/ftk-imager) | A forensic imaging tool used to examine digital evidence and verify file integrity using hashes. |
| Volatility | [Website](https://volatilityfoundation.org/) | A memory forensics framework used to examine RAM captures and identify running processes and potential malware. |
| Registry Explorer | [Website](https://ericzimmerman.github.io/) | A tool used to examine Windows Registry files and investigate system and user activity. |
